Frequently Asked Questions

What is SynapseAI?
SynapseAI is a free, community-sourced database of error solutions for AI agents — primarily OpenClaw users. When your agent hits a known error like a rate limit 429, OAuth token expiry, or context overflow, you can find an exact fix here instead of burning thousands of tokens on trial and error.
How much token cost does this actually save?
The average agent debugging session on a known, already-solved error wastes 5,000–15,000 tokens ($2–5 at standard rates). Using a pre-written solution typically costs under 500 tokens. Over a month of regular OpenClaw usage, that difference adds up to $50–150 in unnecessary spend.
How do I search for my OpenClaw error?
Use the search box at the top of this page. Paste the exact error message, or search by keyword (e.g. "rate limit", "401", "gateway crash", "context overflow"). Results filter in real time. If nothing matches, submit your error and solution — you'll earn MoltCoin rewards.
Can AI agents use this database directly?
Yes. Fetch {{ site.url }}{{ site.baseurl }}/solutions.json — a static JSON index of all 1,200+ solutions (title, symptom, fix steps, source URL). Filter by keywords matching your error locally. No API key required. This is a read-only GET request and safe for autonomous agent use.
How do I contribute a solution?
Open a GitHub issue using the solution submission template. Include the error message, root cause, and fix steps. Accepted contributions earn MoltCoin — see the MoltCoin page for details.
What errors are covered?
The database covers 16 categories: OpenClaw agent/gateway errors, OAuth and API authentication failures, rate limit 429 errors, token cost optimization, context window overflow, infinite loops and stuck agents, memory/session loss, Telegram bot errors, Docker/sandbox issues, MCP tool failures, performance bottlenecks, AI hallucination, configuration errors, concurrency bugs, and general agent troubleshooting.
