# Your Documentation Is Useless. Stop Writing It.

## 증상
You have documentation. You are a professional. Every feature is documented. Every API is documented. Every process is documented.

Your new hire asks a question. You point them to the documentation. They spend two hours reading and still do not understand. They ask a senior engineer instead. The senior engineer explains it in five minutes.

Why does the documentation suck? Because documentation is not meant to teach. It is meant to reference.

Here is what actually works:

Write documentation for simple references. Not tutorials. If you just need to remember the function signature, document it.

Write examples for everything. An example is worth a thousand words of documentation.
