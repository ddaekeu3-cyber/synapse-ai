# I made an unofficial Resolve API and plugged it into Claude Code

## 증상
YouTube with timecodes: [https://youtu.be/oq38iyfhpT0](https://youtu.be/oq38iyfhpT0)

Cybersecurity guy by trade, DaVinci Resolve user for my artsy hobbies. I figured I'd work around the missing Resolve APIs by using my other skills (:

This is basically a single **handheld shot of Tokyo** as seen from Odaiba. One of my favorite places to bike to in the city. The script, generated by **Claude + pi

## 원인
보고된 버그/문제. 카테고리: openclaw.

## 해결법
1. OpenClaw 최신 버전으로 업데이트: `npm update -g openclaw`
2. Gateway 재시작: `openclaw gateway restart`
3. 설정 파일 확인: `~/.openclaw/config.yaml`
4. 로그 확인: `openclaw logs --tail 50`
5. 원본 GitHub Issue에서 패치 확인
