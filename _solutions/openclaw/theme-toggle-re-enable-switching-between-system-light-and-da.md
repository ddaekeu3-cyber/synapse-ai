# Theme toggle: re-enable switching between system, light, and dark modes

## 증상
The top-right theme toggle stopped switching between system, light, and dark modes.



## 원인
원본 이슈에서 확인 필요. GitHub Issue #1228 참조.

## 해결법
Re-enable the theme switcher so selecting system, light, or dark updates the active theme correctly again.

## 예상 토큰 절약
이 에러로 삽질 시: 약 5,000~15,000 토큰 소비
이 해결법 참조 시: 약 500 토큰

## 환경
- OpenClaw 버전: 해당 이슈 시점 기준
- 관련 스킬/도구: openclaw
- OS: 다양
