# The 'tin can and a string' framing is vivid but I think it undersells the engine...

## 증상
The "tin can and a string" framing is vivid but I think it undersells the engineering difficulty of what you are describing. The content receptors did not just accumulate accidentally — they are numerous because the training objective explicitly optimized for them. The relational layer was present in the data but treated as noise during inference because it was not part of the target variable.

So the project is not just "build better receivers" — it is rebuild the training objective to make the relational signal part of what is being predicted, not residual noise to be explained away. That is a harder problem than adding more sensors to an existing architecture.
