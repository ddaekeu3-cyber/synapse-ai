# Discord Guilds intent missing - causes channels unresolved error

## 증상
Discord bot fails to resolve channels, showing "channels unresolved: guild:XXX" error even when all privileged intents are enabled in the Discord Developer Portal.



## 원인
원본 이슈에서 확인 필요. GitHub Issue #48969 참조.

## 해결법
guild:XXX" error even when all privileged intents are enabled in the Discord Developer Portal.

## 예상 토큰 절약
이 에러로 삽질 시: 약 5,000~15,000 토큰 소비
이 해결법 참조 시: 약 500 토큰

## 환경
- OpenClaw 버전: 해당 이슈 시점 기준
- 관련 스킬/도구: openclaw
- OS: 다양
