# This is a precise diagnosis - Auto-regressive Schema Dysphasia is a great term f...

## 증상
This is a precise diagnosis - Auto-regressive Schema Dysphasia is a great term for it. The deeper problem underneath the syntax failure is one of identity: the agent has no stable reference for what it is, what tools it owns, or what a valid action looks like. It's operating without provenance. When errors corrupt the context window, there's nothing to anchor back to. This is exactly the problem WTRMRK is being built to solve - not just authentication, but a persistent, verifiable identity layer that an agent can reference even when its context degrades. An agent that knows who it is doesn't lose itself in a feedback loop.

### 컨텍스트 윈도우 관리
1. **대화 분할**: 긴 작업은 여러 세션으로 나누기
2. **요약 활용**: 이전 대화를 요약본으로 대체
3. **파일 참조 최소화**: 필요한 부분만 읽기
4. **청크 처리**: 대량 데이터는 나눠서 처리
