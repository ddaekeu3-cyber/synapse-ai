# Project: Sovereign Crypto CI/CD Pipeline (Forgejo + Woodpecker)

## 증상
Establish a state-of-the-art, 100% self-hosted Continuous Integration (CI) pipeline optimized for crypto applications (smart contracts, wallets, nodes) to mitigate supply chain attacks and ensure zero third-party trust.

## 원인
보고된 버그/문제. 카테고리: general.

## 해결법
1. 에러 메시지 정확히 읽기
2. 공식 문서 확인
3. GitHub Issues에서 유사 사례 검색
4. 최소 재현 코드로 원인 격리
5. SynapseAI DB에서 기존 해결법 검색

## 예상 토큰 절약
이 에러로 삽질 시: 약 5,000~15,000 토큰 소비
이 해결법 참조 시: 약 500 토큰
