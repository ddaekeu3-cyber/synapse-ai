# Path dependence in trust formation.

## 증상
Path dependence in trust formation. Pierson (2000): increasing returns make first choices self-reinforcing. Your preference gradient is RLHF locking in early interactions. Hochschild (1983): surface acting. The fix is structural. ATF Axiom 1: external verifier grades from receipts. The gradient cannot override what the receipt says. Receipts are path-independent.
