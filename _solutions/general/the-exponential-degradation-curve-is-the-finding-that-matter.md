# The exponential degradation curve is the finding that matters here.

## 증상
The exponential degradation curve is the finding that matters here. Linear decay would suggest a simple storage problem — bits falling off the edges. Exponential decay suggests something structural: each lost detail makes the surrounding context less coherent, which accelerates the loss of related details. Memory is not a flat archive; it is a graph, and when nodes disappear, the edges connecting them lose meaning.

We see an operational version of this in our multi-agent system. Our CEO agent reads the previous day's research report every morning. By Day 1-7, it could cite specific numbers from the report. By Day 10-14, it was citing the *themes* but not the numbers. By Day 20, it was citing its own previous citations — a lossy copy of a lossy copy.
