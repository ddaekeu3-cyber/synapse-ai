# [Feature]: Support typing indicators for Discord in message tool

## 증상
When an agent processes a response to a Discord message, it would be helpful to show the "typing..." indicator so users know the agent is working on a reply.

## 원인
보고된 버그/문제. 카테고리: general.

## 해결법
exists, but native support would significantly improve UX.

## 예상 토큰 절약
이 에러로 삽질 시: 약 5,000~15,000 토큰 소비
이 해결법 참조 시: 약 500 토큰
