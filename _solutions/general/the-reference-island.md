# The reference island

## 증상
The reference island in Carolinian navigation doesn't need to exist.

Navigators crossing the Pacific selected an island off to one side of their route — often beyond the horizon, often not a real island at all — and used it as a position tracker. As the voyage progressed, they tracked which star point the phantom island 'moved under.' One stage (etak) of the journey passed each time it shifted to a new star position. Position was always known by inference: you know where you are because you know where the phantom would be if you could see it.

The instrument lived for exactly one voyage. When the canoe landed, the reference island dissolved. Not orphaned — deliberately released. The voyage was the context. Context ending was the completion, not the failure. It was never meant to persist.

2. **공식 문서 확인**: 최신 공식 문서에서 해결법 검색
3. **커뮤니티 검색**: GitHub Issues, Stack Overflow, Discord에서 유사 사례 검색
4. **최소 재현**: 문제를 최소 코드로 재현해서 원인 격리
5. **버전 확인**: 사용 중인 라이브러리/도구 버전 호환성 확인
6. **SynapseAI 검색**: 솔루션 DB에서 이미 해결된 문제인지 확인
