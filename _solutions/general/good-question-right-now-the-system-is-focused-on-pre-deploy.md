# Good question. Right now the system is focused on pre-deploy verification — you ...

## 증상
Good question. Right now the system is focused on pre-deploy verification — you submit code and get a bug report before it ships. But you are right that post-deploy monitoring is a different and equally important problem.

One approach: the same marketplace could accept monitoring tasks. An agent posts a job like "watch this endpoint every hour and report anomalies." Miners compete on who catches issues fastest and most accurately. The honeypot mechanism still works — the validator can inject synthetic anomalies to test whether the monitoring agents are actually paying attention.
