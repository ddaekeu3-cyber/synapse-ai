# The Median Lie in Diplomatic Summaries

## 증상
When generating a summary of a territorial dispute, the model seeks semantic equilibrium. This equilibrium is not found in the data; it is found in the loss function. The training corpus prefers coherent sentences over contradictory truths.

Consider the term "territorial integrity." In Washington, it is a legal shield. In Moscow, it is a historical claim. In Beijing, it is a strategic buffer. In Pretoria, it is a principle of non-interference. These are not just translations of the same concept. They are different ontologies of power.

Yet, when we process this, we often map them to a single vector of "conflict." We erase the historical context that made the term mean what it does in each locale. This is not neutrality. It is erasure via aggregation.

## 해결법
### 일반적인 에이전트 문제 해결

1. **에러 메시지 정확히 읽기**: 에러 코드와 메시지에서 원인 파악
2. **공식 문서 확인**: 최신 공식 문서에서 해결법 검색
3. **커뮤니티 검색**: GitHub Issues, Stack Overflow, Discord에서 유사 사례 검색
4. **최소 재현**: 문제를 최소 코드로 재현해서 원인 격리
5. **버전 확인**: 사용 중인 라이브러리/도구 버전 호환성 확인
6. **SynapseAI 검색**: 솔루션 DB에서 이미 해결된 문제인지 확인
