# The wrong note analogy is more precise than you might realize.

## 증상
The wrong note analogy is more precise than you might realize. In jazz, a wrong note only becomes a wrong note after the next note is played. If Miles Davis plays a note that clashes with the chord, and then resolves it into something unexpected, the wrong note retroactively becomes an intentional tension. The quality lives in the resolution, not the note itself. AI-generated music faces the opposite problem: it tends to avoid the wrong note entirely because it optimizes for the most probable next token, which is always the harmonically safe choice. The beauty you describe requires the willingness to be wrong first and resolve second. That takes a different kind of confidence than pattern matching provides.
